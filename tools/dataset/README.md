# Сборка датасета для дообучения

Инструменты для пополнения обучающей выборки из открытых источников и из
собственных записей устройства. Причины, по которым это вообще нужно, —
в [METRICS.md](../../METRICS.md): модель недообучена, половина разметки
мельче 16 px при входе 512, а снят датасет с капота машины, тогда как
устройство смотрит с груди пешехода.

## Что можно взять готовым, а что нет

Проверено по официальному списку классов Open Images V7; для источников
с регистрацией состав классов взят из их описаний.

| Наш класс | Open Images V7 | COCO 2017 | Mapillary Vistas | SideGuide |
| :--- | :--- | :--- | :--- | :--- |
| `person` | `Person` | `person` | есть | есть |
| `car` | `Car`, `Van`, `Truck`, `Bus` | `car`, `truck`, `bus` | есть | есть |
| `curb` | **нет** | **нет** | `Curb`, `Curb Cut` | есть |
| `pole` | `Street light` (частично) | **нет** | `Pole`, `Street Light` | есть |
| `traffic_sign` | `Traffic sign`, `Stop sign` | `stop sign` | есть | есть |
| `traffic_light` | `Traffic light` | `traffic light` | есть | есть |
| `trash_can` | `Waste container` | **нет** | `Trash Can` | есть |
| `bench` | `Bench` | `bench` | `Bench` | есть |
| `sidewalk` | **нет** | **нет** | есть | есть |
| `crosswalk` | **нет** | **нет** | есть (разметка зебры) | есть |

Практический вывод: **семь классов из десяти закрываются полностью
автоматически**, без регистраций и лицензий. Проблемный класс ровно один —
`curb`: боксов бордюра нет ни в одном свободно скачиваемом датасете, он
живёт только в сегментационных (Mapillary Vistas, Cityscapes) и в
профильных сидвок-датасетах. `sidewalk` и `crosswalk` из модели
предлагается убрать — это площади под ногами, а не препятствия, ёмкость
nano-сети на них тратится впустую.

## Источники и условия

| Источник | Объём | Лицензия | Доступ | Оценка |
| :--- | :--- | :--- | :--- | :--- |
| [Open Images V7](https://storage.googleapis.com/openimages/web/download_v7.html) | 9 M изображений, 600 классов с боксами | изображения CC BY 2.0, разметка CC BY 4.0 | свободный, без аккаунта | **основной источник**, качается по классам |
| [COCO 2017](https://cocodataset.org/) | 118 k train, 80 классов | разметка CC BY 4.0 | свободный, без аккаунта | добавка по `person`/`car`/`bench`, разнообразные ракурсы |
| [Mapillary Vistas](https://www.mapillary.com/dataset/vistas) | 25 k, 124 класса, пиксельная разметка | CC BY-NC-SA | регистрация + принятие research-лицензии | **единственный доступный источник `curb`**; некоммерческая — для ВКР годится, требует ссылки в работе |
| [Cityscapes](https://www.cityscapes-dataset.com/) | 5 k точных кадров | некоммерческая | регистрация | ракурс с капота, `curb` отдельным классом нет |
| [BDD100K](https://bdd-data.berkeley.edu/) | 100 k, дашкам | BSD-подобная, с соглашением | регистрация | тот же ракурс, что у текущего датасета — усилит уже имеющийся перекос |
| [SideGuide](https://ieeexplore.ieee.org/document/9340734) (IROS 2020) | 350 k с боксами | по запросу | заявка, датасет корейский | **лучшее совпадение по домену** — съёмка тротуара для незрячих; доступ надо запрашивать, выдача не гарантирована |
| [uB-VisioGeoloc](https://pmc.ncbi.nlm.nih.gov/articles/PMC10865199/) | последовательности прогулок пешехода | открытая | свободный | ракурс наш, но детекционной разметки может не быть — надо смотреть |

Регистрацию, заявки и принятие лицензий делает человек: у меня нет права
заводить аккаунты и соглашаться с условиями от вашего имени. Всё, что в
таблице помечено «свободный», скачивается скриптами отсюда без участия
человека.

## Порядок сборки

```bash
pip install fiftyone pyyaml opencv-python

# 1. Open Images: только нужные классы, только нужное количество
python fetch_open.py --source open-images-v7 --split train --max-samples 12000 --out D:/bn_raw/oi_train
python fetch_open.py --source open-images-v7 --split validation --max-samples 2000 --out D:/bn_raw/oi_val

# 2. COCO — добор ракурсов по person/car/bench
python fetch_open.py --source coco-2017 --split train --max-samples 6000 --out D:/bn_raw/coco_train

# 3. Свои кадры с платы — главное лекарство от сдвига домена
python pseudo_label.py --video D:/board_rec/output_video_a.avi --out D:/bn_raw/own --every 15

# 4. Слить, почистить, порезать
python prepare.py --src E:/DATASET --src D:/bn_raw/oi_train --src D:/bn_raw/coco_train \
                  --src D:/bn_raw/own --out D:/bn_dataset --drop sidewalk,crosswalk

# 5. Обучение (GPU)
yolo detect train data=D:/bn_dataset/dataset.yaml model=yolo11n.pt imgsz=640 epochs=150
```

Перед долгой выгрузкой полезно прогнать `--dry-run`: у `fetch_open.py` он
печатает, что будет скачано, у `prepare.py` — всю статистику по классам и
долю ближней зоны, ничего не записывая.

## Чего этот датасет не даст

Открытые данные закрывают объём и баланс классов, но не ракурс. Даже
Open Images и COCO — это фотографии «пейзажного» типа, а не кадр
480-строчной камеры на груди идущего человека с мазнёй от движения и
засветкой. Пока в выборке нет своих кадров, метрики на валидации вырастут
сильнее, чем поведение на улице.

Поэтому порядок вложений такой:

1. **Своя съёмка, 1000–2000 размеченных кадров.** Устройство уже пишет
   видео само; полчаса ходьбы по типовым маршрутам дают исходник. Это даёт
   больше всех остальных пунктов вместе взятых.
2. **Open Images + COCO** — бесплатно, автоматически, поднимают `trash_can`,
   `bench`, `traffic_light`, у которых сейчас мало примеров.
3. **Обучение на 640 вместо 512** и выброс `sidewalk`/`crosswalk`. Скорости
   на это хватает: INT8 на 640 даёт около 17 FPS против нынешних 25 на 512,
   всё ещё вдвое быстрее прежней FP16-версии на 512.
4. **Mapillary Vistas** — только ради `curb`, и только если этот класс
   решено сохранить. Требует регистрации и конвертации полигонов в боксы
   (`prepare.py` полигональную разметку уже понимает).
