# Калибровка фокусного расстояния камеры

Заменяет прикидку `FOCAL_LENGTH = 252.0f` (посчитанную по FOV из даташита,
см. [CALIBRATION.md](../../CALIBRATION.md)) на измеренное значение конкретной
камеры. Без этого шага дистанция в `compute_distance()` ошибается на
постоянный множитель — не хаотично, а систематически в одну сторону.

Нужен человек физически у платы: доску держит и поворачивает живой человек,
скрипт только фотографирует и считает.

## Порядок

1. Распечатать `chessboard_9x6.png` — 10x7 клеток, 9x6 внутренних углов.
   Приклеить на что-то жёсткое (картон, планшет), иначе неровности бумаги
   портят детекцию углов. Линейкой измерить реальный размер одной клетки на
   распечатке в мм — принтер почти никогда не даёт 1:1 с PDF.

2. На плате:
   ```bash
   scp tools/calib/capture_chessboard.py root@newloggervalya.local:/root/
   ssh root@newloggervalya.local
   systemctl stop blind_nav_main   # камера занята основным процессом
   python3 /root/capture_chessboard.py --cols 9 --rows 6 --out /root/calib_frames
   ```
   Держать доску перед камерой: по центру и у всех четырёх краёв кадра,
   близко и далеко, с наклоном вперёд/назад и вбок. Скрипт сам сохраняет
   кадр, когда находит на нём доску, и печатает номер. Останавливать
   Ctrl+C на 15-20 сохранённых кадрах.

3. Посчитать интринсики (можно там же на плате или скопировав кадры на ПК):
   ```bash
   python3 tools/calib/compute_intrinsics.py \
       --frames /root/calib_frames --cols 9 --rows 6 --square <мм из шага 1>
   ```
   Печатает `fy` — это и есть новое `FOCAL_LENGTH`, RMS ошибку репроекции
   (должна быть < 1 px, иначе переснять с более разными углами) и
   `distCoeffs` на будущее для `cv::undistort`.

4. Подставить `fy` в `FOCAL_LENGTH` в `main.cpp`, `rknn_image_test.cpp`,
   `rknn_video_bench.cpp` вместо `252.0f`, обновить комментарий и
   `CALIBRATION.md`, пересобрать.

5. Не забыть `systemctl start blind_nav_main` — камера нужна и там.

Дальше по плану — шаг 4 из `CALIBRATION.md`: разметить контрольные точки на
1/2/3/5/8 м и на слух/по логу сверить озвучиваемую дистанцию с реальной.
